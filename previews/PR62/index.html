PiecewiseLinearOpt.jl

PiecewiseLinearOpt.jl is a JuMP extension for modeling optimization problems containing piecewise linear functions, possibly nonconvex and of several variables.

The package accompanies the paper Nonconvex piecewise linear functions: Advanced formulations and simple modeling tools by Joey Huchette and Juan Pablo Vielma, and implements the formulations from it together with other formulations from the literature, see Formulation methods and References.

Version 0.5 is a rewrite of the code introduced with the paper, with a new interface. The original code can be found in the v0.4.2 release, the last of version 0.4.

Installation

import PkgPkg.add("PiecewiseLinearOpt")

Quick start

To minimize a piecewise linear approximation of $\sin(x)$ with breakpoints at 0:0.5:2π:

using JuMP, PiecewiseLinearOpt, HiGHSmodel = Model(HiGHS.Optimizer)set_silent(model)@variable(model, x)y = piecewiselinear(model, x, 0:0.5:2π, sin)@objective(model, Min, y)optimize!(model)value(x), value(y)
(4.5, -0.977530117665097)

The output y equals the piecewise linear function of x, which is formulated with auxiliary variables and constraints. Functions of two variables work the same way, with breakpoints along each axis:

model = Model(HiGHS.Optimizer)set_silent(model)@variable(model, x)@variable(model, y)z = piecewiselinear(model, x, y, 0:0.25:1, 0:0.25:1, (a, b) -> (a - 0.3)^2 + (b - 0.6)^2)@objective(model, Min, z)optimize!(model)value(x), value(y), value(z)
(0.25000000000000033, 0.5000000000000006, 0.012499999999999994)
