Migrating from version 0.4

Version 0.5 is a rewrite with a new interface. The main changes are:

  • Methods are values of their own types instead of symbols, e.g. method = Logarithmic() instead of method = :Logarithmic.
  • The general piecewiselinear method takes a vector of inputs and returns a vector of outputs together with a PWLFormulation. The convenience methods for univariate and bivariate functions still return the output only.
  • The triangulation of bivariate functions is given as a value with the triangulation keyword instead of the pattern keyword, and the default is now K1Triangulation instead of best fit. The default method of bivariate functions depends on the triangulation, see Formulation methods, instead of always being the six-stencil formulation; pass method = SixStencil() to keep it.
  • Functions may have several outputs, more than two inputs and, for some methods, discontinuities.
  • The direction keyword takes Epigraph() or Hypograph() for a function that is only bounded from one side, instead of modeling its graph.
